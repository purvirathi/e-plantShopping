# Paradise Nursery

Paradise Nursery is a React-based e-commerce front end for browsing houseplants and managing a shopping cart. Built as the capstone project for the Full Stack Application Development course.

## Features
- Landing page with company introduction
- Product listing page with plants grouped into categories
- Shopping cart with quantity controls and live totals
- State managed with Redux Toolkit

## Tech Stack
- React
- Redux Toolkit / react-redux
- CSS

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
